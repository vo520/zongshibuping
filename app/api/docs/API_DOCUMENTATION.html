🚀 快速开始

安装依赖

npm install axios

快速示例

import axios from 'axios';

// 创建 API 客户端
const api = axios.create({
  baseURL: 'https://api.your-domain.com',
  timeout: 10000,
});

// 获取文章列表
async function getArticles() {
  const response = await api.get('/article/list', {
    params: { lang: 'zh', page: 1, pageSize: 10 }
  });
  console.log(response.data);
}
💡 提示: 所有公开接口均支持 CORS，可直接从前端调用，无需配置代理。

公开接口（无需认证）

以下接口无需任何认证即可访问：

/api/column/list, /api/column/tree
/api/article/list, /api/article/recommend, /api/article/hot
/api/product/list, /api/product/recommend
/api/other/* (slides, links, tags, nav, config)

签名认证（可选）

对于需要认证的接口，请在请求头中添加以下参数：

参数 说明 示例
X-App-Id 应用 ID app_001
X-Timestamp 时间戳（秒） 1704067200
X-Signature 签名 a1b2c3d4e5f6...
⚠️ 注意: 签名算法需要联系管理员获取 App Secret，请勿在前端暴露密钥。

🛠 SDK 使用指南

React Hooks 封装

import { useState, useEffect, useCallback } from 'react';
import axios from 'axios';

const api = axios.create({
  baseURL: process.env.REACT_APP_API_URL,
  timeout: 10000,
});

export const useArticleList = (params = {}) => {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  const fetchData = useCallback(async () => {
    setLoading(true);
    try {
      const response = await api.get('/article/list', { params });
      if (response.data.code === 1) {
        setData(response.data.data.list);
      } else {
        setError(response.data.msg);
      }
    } catch (e) {
      setError(e.message);
    } finally {
      setLoading(false);
    }
  }, [JSON.stringify(params)]);

  useEffect(() => { fetchData(); }, [fetchData]);

  return { data, loading, error, refetch: fetchData };
};

Vue Composable 封装

import { ref, readonly } from 'vue';
import axios from 'axios';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
  timeout: 10000,
});

export function useApi() {
  const loading = ref(false);
  const error = ref(null);

  async function request(method, url, params) {
    loading.value = true;
    error.value = null;
    try {
      const response = method === 'get'
        ? await api.get(url, { params })
        : await api.post(url, params);
      return response.data;
    } catch (e) {
      error.value = e.response?.data?.msg || '请求失败';
      throw e;
    } finally {
      loading.value = false;
    }
  }

  return { request, loading: readonly(loading), error: readonly(error) };
}

❓ 常见问题

Q1: 如何处理跨域问题？ ▶

API 已配置 CORS 头部，公开接口支持跨域请求，无需额外配置。

Q2: 如何处理请求超时？ ▶ 
api.get('/article/list', { timeout: 5000 });
Q3: 如何缓存 API 响应？ ▶

推荐使用 SWR 或 React Query 进行数据缓存：

import useSWR from 'swr';

function ArticleList() {
  const { data } = useSWR('/api/article/list', fetcher, {
    revalidateOnFocus: false
  });
}
Q4: 如何实现自动重试？ ▶ 
import axiosRetry from 'axios-retry';

axiosRetry(api, {
  retries: 3,
  retryDelay: (count) => count * 1000
});

🔒 安全注意事项

⚠️ 重要提醒:
  • 不要在前端代码中硬编码 API 密钥
  • 使用环境变量存储敏感配置
  • 生产环境务必启用 HTTPS
  • 对用户输入进行 HTML 转义

  const timestamp = Math.floor(Date.now() / 1000);
  const appId = process.env.API_APP_ID;
  const secret = process.env.API_SECRET;
